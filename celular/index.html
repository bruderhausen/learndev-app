O LearnDev não conseguiu iniciar

A interface não carregou. Quase sempre é dependência faltando — alguém baixou o projeto e ainda não instalou as bibliotecas.

No terminal, dentro da pasta do projeto:

npm install
npm run dev

Se continuar assim, abra o terminal onde o servidor está rodando: a mensagem de erro de verdade aparece lá, e ela diz o nome do que faltou.
